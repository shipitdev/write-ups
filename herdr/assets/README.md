# Herdr illustrations

Seven original conceptual diagrams, created through Excalidraw MCP. These illustrate the traced implementation; they are not screenshots of Herdr.

| File prefix | Illustration |
| --- | --- |
| `00-cover` | From scattered terminal checks to shared agent status |
| `01-architecture` | Client, server, and terminal processes |
| `02-attention` | Detection signals and lifecycle labels |
| `03-coordination` | Ordered submission, activity gate, and settlement |
| `04-persistence` | Detach versus restart |
| `05-state-runtime` | Terminal records versus live resources |
| `06-output-render` | PTY output and visibility-aware rendering |

The article uses the 1600 × 1200 PNG files for consistent typography on GitHub. SVG versions provide scalable equivalents. The PNG/SVG files are static renders of the diagram geometry; Excalidraw provides its own hand-drawn rendering.

Open any `.excalidraw` file through Excalidraw’s **Open** menu to edit it. `scenes.json` holds the compact elements submitted to the MCP tool.

Visual direction: warm paper, handwritten labels, pastel blocks, dark outlines, and one main idea per image. The illustrations are original, with visual inspiration from the supplied articles.
